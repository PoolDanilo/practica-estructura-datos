# Proyecto de Estructura de Datos

Aplicación de consola en Java que gestiona materias de una carrera mediante una lista enlazada simple.

## Estructura del proyecto

- `Nodo.java`: representa una materia con código, nombre, créditos y enlace al siguiente nodo.
- `Lista.java`: contiene las operaciones de inserción, búsqueda, recorrido, actualización y eliminación.
- `Principal.java`: presenta el menú de consola para probar el programa.

## Operaciones incluidas

- Insertar al inicio.
- Insertar al final.
- Insertar ordenado por código.
- Insertar por referencia.
- Buscar y mostrar materias.
- Actualizar una materia.
- Eliminar una materia.

## Ejecución en NetBeans

Crear un proyecto Java, agregar el paquete `tareaunidad1`, copiar los tres archivos de `src/tareaunidad1` y ejecutar la clase `Principal`.
